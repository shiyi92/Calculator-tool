# 项目费用汇总工具

一个零依赖的响应式网页/PWA，用于在电脑和手机上录入项目合同、付款和费用明细，并自动计算汇总。

## 计算规则

- 未付款金额 = 合同含税金额 - 已付款金额
- 人工费 = 所有人员的（工期 × 单价）累计
- 材料费 = 所有产品的（单价 × 使用数量）累计
- 其它费用 = 所有其它费用明细金额累计
- 总费用 = 人工费 + 材料费 + 其它费用
- 费用占比 = 项目总费用 ÷ 合同含税金额 × 100%
- 不含税金额 = 合同含税金额 ÷（1 + 税率 ÷ 100）
- 预估结余 = 合同含税金额 - 总费用

## 功能

- 新增、编辑、删除、搜索和按项目日期年份筛选项目
- 人工费、材料费、其它费用明细的新增、编辑和删除
- 从项目列表点击费用金额直接维护对应明细
- 项目详情集中展示项目字段和全部费用明细
- 自动计算不含税金额、费用占比、未付款、总费用和预估结余
- 数据自动保存在当前浏览器的 Local Storage
- JSON 备份导入/导出，完整保留费用明细
- CSV 导出，可使用 Excel 打开
- 打印项目列表
- 响应式手机布局
- 支持 PWA 安装和离线访问

## 旧数据兼容

- 旧数据的项目年份会转换为该年度的 1 月 1 日，例如 `2026` 转为 `2026-01-01`。
- 旧人工费、材料费和其它费用聚合金额会分别转换为一条“历史汇总”明细，原金额不会丢失。

## 本地运行

在 PowerShell 中执行：

```powershell
python -m http.server 8080 --directory "C:\webull\git\webull-trade-kiro\Calculator-tool"
```

电脑浏览器访问：

```text
http://localhost:8080
```

不要直接双击 `index.html` 调试 PWA，因为 Service Worker 需要通过 HTTP/HTTPS 运行。

## 手机访问

1. 手机和电脑连接同一个 Wi-Fi。
2. 在电脑执行 `ipconfig`，找到 IPv4 地址，例如 `192.168.1.20`。
3. 手机访问 `http://192.168.1.20:8080`。
4. 如果无法访问，请确认 Windows 防火墙已允许 Python 访问专用网络。

手机通过局域网 HTTP 可以使用主要功能，但部分浏览器要求 HTTPS 才显示“安装到设备”。正式安装可部署到任意 HTTPS 静态站点。

## 数据说明

数据只保存在当前设备、当前浏览器中。清理浏览器数据会删除项目记录，请定期点击“导出备份”。不同设备之间可使用 JSON 备份文件迁移数据。
